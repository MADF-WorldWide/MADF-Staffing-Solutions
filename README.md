# MADF WorldWide recruitment website

This repository contains a static GitHub Pages website for **MADF WorldWide**, owned by **Melissa Steele**.

## Pages included

- `index.html` — home page with hero, role links, community visuals, and share buttons
- `about.html` — company overview and process
- `roles.html` — preferred role descriptions
- `apply.html` — detailed employment interest/application form
- `contract.html` — employment agreement template and agreement review request form
- `policies.html` — privacy, applicant consent, equal opportunity, website terms, data retention, and other policy notices
- `contact.html` — contact details and general enquiry form

## Contact routing

All forms are client-side and open an email preview addressed to:

`melissasteele462@outlook.com`

This is intentional so the site can run on GitHub Pages without a server. Very long forms may exceed mail app URL limits, so each form also shows a copyable text preview.

## GitHub Pages deployment

A workflow is included at `.github/workflows/pages.yml` to publish the static site through GitHub Pages.

After pushing to `main`, open the repository settings and confirm Pages is set to deploy from **GitHub Actions** if GitHub asks you to choose a source.

## Legal review

The employment agreement and policies are templates. Have a qualified employment/privacy attorney review them before official use, especially for worker classification, commissions, PTO, healthcare, parental leave, wage payments, contractor status, final pay, and Europe-specific employment/data rules.
